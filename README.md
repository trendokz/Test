# 3D-конструктор украшений

Сайт-конструктор колец и пусет с бриллиантами. Покупатель:

1. выбирает одну или несколько форм бриллианта (10 огранок);
2. смотрит каталог изделий с 3D-превью и ценами «от»;
3. открывает изделие в 3D-конструкторе: крутит его мышью или пальцем, приближает, переключает ракурсы (3/4, спереди, сбоку, сверху), включает автовращение 360° и полноэкранный режим;
4. настраивает изделие: форму камня, шинку, касту, карат, металл и металл касты, пробу, цвет центрального и боковых камней, размер кольца. Цена пересчитывается сразу;
5. отправляет заявку в WhatsApp (выбор города) или делится ссылкой на свою конфигурацию.

Все 3D-модели строятся в коде (Three.js), внешние модели и платные сервисы не нужны.

## Ассортимент

Формы камня (в порядке показа): круглый, принцесса, радиант, кушон, овал, груша, сердце, маркиз, изумруд, ашер.

Кольца — 9 моделей на каждую форму (`RING_MODELS` в `js/config.js`), в каталоге по возрастанию цены:

| Модель | Описание | Касты |
|---|---|---|
| Solo | классический солитер | крапаны, ореол |
| Solo Pavé | солитер с дорожкой камней | крапаны, ореол |
| Trio | трилогия: центральный камень и две груши | крапаны, ореол |
| Trio Pavé | трилогия с дорожкой камней | крапаны, ореол |
| Bezel | камень в сплошном ободке | безель |

Пусеты: Classic — все 10 форм, Halo — круглый, овал, груша, маркиз, изумруд, радиант. Цена пусет — по запросу (`price: null`).

## Запуск

Это статический сайт без сборки. Нужен любой веб-сервер (открыть `index.html` двойным кликом не получится из-за ES-модулей):

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

Для публикации подойдёт любой статический хостинг: GitHub Pages, Netlify, Vercel, обычный хостинг. Достаточно загрузить все файлы репозитория.

## Настройка под свой бренд

Всё редактируется в одном файле, **`js/config.js`**:

| Что | Где |
|---|---|
| Название, слоган, валюта | `BRAND` |
| Номера WhatsApp по городам | `BRAND.cities` — **замените заглушки `77000000000` на свои номера** |
| Модели шинок и их цены | `SHANKS` |
| Касты и доплаты | `SETTINGS`, `SETTING_SHAPES` (какие формы доступны для Halo) |
| Металлы, пробы, цвета камней | `METALS`, `PURITIES`, `STONE_COLORS` |
| Караты и размеры | `CARATS`, `RING_SIZES` |
| Пусеты | `STUD_SETTINGS` |
| Формула цены | `PRICING`; сама формула — `priceOf()` в `js/main.js` |

Цвета и шрифты сайта задаются переменными в начале `css/style.css`.

## Структура

```
index.html          — точка входа
css/style.css       — оформление (адаптивное, телефон и компьютер)
js/config.js        — настройки магазина
js/main.js          — страницы, роутинг, цены, заявка
js/shapes.js        — контуры 10 огранок, SVG-иконки форм
js/jewelry.js       — построение 3D-моделей: камни, шинки, касты, пусеты
js/viewer.js        — 3D-сцена: студийный свет, вращение, ракурсы, превью каталога
vendor/three/       — библиотека Three.js r170 (MIT)
```

## Ссылки на конфигурации

Каждая конфигурация хранится в адресе страницы, например
`#/ring?shape=oval&shank=pave&setting=halo&carat=1.5&metal=rose&size=17`.
Такую ссылку можно отправить клиенту, и у него откроется то же изделие. Она же автоматически прикладывается к заявке в WhatsApp.

## Если появятся профессиональные 3D-модели

Модели в коде упрощённые. Если у вас будут модели от 3D-дизайнера в формате `.glb`, их можно подключить через `GLTFLoader` из Three.js вместо функций `buildShank` / `buildHead` в `js/jewelry.js`. Материалы металла и камней из `MaterialLibrary` можно использовать и для загруженных моделей.
